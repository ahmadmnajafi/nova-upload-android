# Nova Uploader

اپ سبک اندروید برای آپلود عکس/ویدیو به گالری نوا **بدون ورود به پنل وب**.

## قابلیت‌های اسکلت فعلی

- ورود با OTP موبایل (همان سیستم مشتریان نوا)
- ذخیره توکن دستگاه روی گوشی
- لیست دسته‌بندی‌ها و انتخاب دسته
- انتخاب چند فایل از گالری
- **Share Target**: از گالری گوشی → اشتراک‌گذاری → Nova Uploader
- نوار ارسال هنگام فرستادن فایل
- منو: بروزرسانی دسته‌ها، آپدیت اپ، خروج

## پیش‌نیاز سرور

روی سایت گالری این فایل‌ها باید دیپلوی شده باشند:

- `nova-upload-app-api.php`
- پشتیبانی `app_token` در `nova_upload_dual`

API پایه پیش‌فرض:

`https://g.novatouch.ir/wp-admin/admin-ajax.php`

برای تغییر، در `app/build.gradle.kts` مقدار `API_BASE` را عوض کنید.

## ساخت APK

```bash
cd nova-upload-android
./gradlew :app:assembleDebug
```

خروجی:

`app/build/outputs/apk/debug/app-debug.apk`

## جریان کاربر

1. نصب اپ و ورود با شماره موبایل + کد
2. یا از گالری گوشی Share بزنید روی «Nova Uploader»
3. دسته را انتخاب کنید
4. ارسال. نوار پایین درصد ارسال را نشان می‌دهد.

منوی همبرگری: بروزرسانی لیست دسته‌ها، بررسی آپدیت، خروج.

آپدیت از سرور گالری خوانده می‌شود. تا وقتی گزینه `nova_upload_app_release` در وردپرس تنظیم نشده باشد، اپ می‌گوید همین نسخه نصب است. برای منتشر کردن نسخه جدید:

```php
update_option('nova_upload_app_release', [
    'version_code' => 3,
    'version_name' => '0.3.0',
    'apk_url' => 'https://g.novatouch.ir/NovaUploader.apk',
    'notes' => 'توضیح کوتاه',
]);
```

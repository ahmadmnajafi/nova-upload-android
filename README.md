# Nova آپلود

اپ سبک اندروید برای آپلود عکس/ویدیو به گالری نوا **بدون ورود به پنل وب**.

## قابلیت‌های اسکلت فعلی

- ورود با OTP موبایل (همان سیستم مشتریان نوا)
- ذخیره توکن دستگاه روی گوشی
- لیست دسته‌بندی‌ها و انتخاب دسته
- انتخاب چند فایل از گالری
- **Share Target**: از گالری گوشی → اشتراک‌گذاری → Nova آپلود
- صف آپلود ساده با گزارش موفق/ناموفق

## پیش‌نیاز سرور

روی سایت گالری این فایل‌ها باید دیپلوی شده باشند:

- `nova-upload-app-api.php`
- پشتیبانی `app_token` در `nova_upload_dual`

API پایه پیش‌فرض:

`https://g.novatouch.ir/wp-admin/admin-ajax.php`

برای تغییر، در `app/build.gradle.kts` مقدار `API_BASE` را عوض کنید.

## ساخت APK

```bash
cd nova-upload-android
./gradlew :app:assembleDebug
```

خروجی:

`app/build/outputs/apk/debug/app-debug.apk`

## جریان کاربر

1. نصب اپ و ورود با شماره موبایل + کد
2. یا از گالری گوشی Share بزنید روی «Nova آپلود»
3. دسته را انتخاب کنید
4. آپلود

## فازهای بعدی پیشنهادی

- فشرده‌سازی تصویر قبل از ارسال
- صف آفلاین / ادامه بعد از قطع اینترنت
- ویجت آپلود سریع
- اعلان موفقیت
